# 材料性能预测系统

基于机器学习的无机材料性能预测工具：输入配方参数，预测材料性能（如抗弯强度、烧结温度）。

## 背景

传统陶瓷/无机材料配方设计依赖大量试烧实验，周期长、成本高。
本项目用机器学习方法，从公开材料数据库中学习"成分-工艺-性能"的规律，
辅助快速筛选候选配方。

## 技术栈

- Python
- pandas（数据处理）
- scikit-learn（机器学习）
- Flask（Web 界面）
- Materials Project API（数据来源）
